# Hanumantha L. — Personal Portfolio

My personal developer portfolio showcasing my projects, technical skills, and interests in software engineering and AI.

🌐 **Live Website:** [hanumantha-portfolio.vercel.app](https://hanumantha-portfolio.vercel.app/)

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Geist Font
- Vercel

## Features

- Responsive design for desktop and mobile
- Dark and light themes
- Project showcase with GitHub and live demo links
- Smooth navigation
- Accessible and lightweight interface

## Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/hanuma-svg/hanumantha-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd hanumantha-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
